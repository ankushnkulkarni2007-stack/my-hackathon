# Onboarding Checklist

- [ ] Clone repo: `git clone https://github.com/ankushnkulkarni2007-stack/my-hackathon.git`
- [ ] Copy env file: `cp .env.example .env` and fill in keys
- [ ] Install deps: `npm install`
- [ ] Run locally: `npm run dev`
- [ ] Confirm app loads at http://localhost:3000

## Emergency (offline mode)
- [ ] Local bare repo path: `/path/to/local-bare-repo.git`
- [ ] Add as remote: `git remote add local /path/to/local-bare-repo.git`
- [ ] Push/pull: `git push local main` / `git pull local main`
