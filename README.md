# My Hackathon Project

A business website built for the Odoo x NMIT Bangalore Hackathon 2026, showcasing company/service info with a lightweight backend for dynamic content.

## Tech Stack
- Frontend: HTML, CSS, JavaScript
- Backend: Node.js, Express
- Database: SQLite

## Setup
```bash
git clone https://github.com/ankushnkulkarni2007-stack/my-hackathon.git
cd my-hackathon
npm install
cp .env.example .env
npm run dev
```

## Folder Structure
```
/src         - application source code (frontend + backend)
/.github     - CI workflows
/docs        - onboarding & architecture notes
```
